# 💡 Task Recommendation Engine

Renders dynamic, clinical situation analysis and actionable recovery or study steps.

---

## 🎯 Features

- **Dynamic Explanation:** Analyzes current Beta/Alpha ratios and heart rate levels to explain student cognitive stress.
- **Actionable Steps:** Recommends specific study tasks, break durations, or breathing exercises.
- **Q-Learning Feedback:** Updates action difficulty levels based on real-time biometric feedback.
