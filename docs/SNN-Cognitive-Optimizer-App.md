# 📱 Cognitive Optimizer App Root

The root entry point, build configuration, and container deployment wrapper.

---

## ⚙️ Build & Operational Setup

- **Frontend Core:** React 18 + Vite (`frontend/src/App.jsx`).
- **Strict Port Enforcement:** Configured in `frontend/vite.config.js` to strictly enforce port `5173`.
- **Auto-Kill Hook:** Pre-dev script automatically frees port `5173` on startup.
- **Docker Compose:** Launch via `docker compose up` for full-stack isolation.
