# 🗓️ Progress Calendar & Rollover Framework

`ProgressCalendar.jsx` provides longitudinal tracking of daily cognitive states with automated 12:00 AM midnight date synchronization.

---

## 🔒 Key Capabilities

1. **Automated 12:00 AM Rollover:** Automatically shifts active session borders at midnight without page refresh.
2. **Future Date Locking:** Disables edit controls (`🔒`) for upcoming dates to enforce data integrity.
3. **Current Session Outline:** High-visibility green border and pulse indicator highlighting "Today".
4. **Interactive Notes Modal:** Enables custom note recording for past and present sessions.
