# 🧱 UI Component Library

Modular React components designed according to clinical off-white & emerald green design guidelines.

---

## 📦 Primary Components

- `Header.jsx`: Navigation & stream simulation controls.
- `CurrentStateCard.jsx`: Real-time cognitive state status card.
- `BiometricTrendsChart.jsx`: Live EEG & heart rate charts.
- `TaskRecommendationCard.jsx`: Adaptive workload recommendations.
- `ProgressCalendar.jsx`: [[SNN-Progress-Calendar-and-Rollover]] interface.
- `GlowButton.jsx`: Custom glowing button controls.
