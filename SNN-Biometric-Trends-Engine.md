# 📈 Biometric Trends Engine

Visualizes real-time EEG Alpha, Beta, and Heart Rate trends using Recharts.

---

## 🎨 Visualization Features

- **Live Plotting:** Smooth area & line curves showing 25 sliding time frames.
- **Custom Tooltips:** Clinical dark-mode tooltip cards displaying instant numeric values.
- **Synthetic Exam Crunch:** Pre-loaded timeline for instant demo validation.
